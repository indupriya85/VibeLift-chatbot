# VibeLift - Mental Health Support Chatbot

VibeLift is an AI-powered mental health support chatbot developed using Python and Streamlit. It provides a supportive conversational environment where users can express their thoughts, emotions, stress, and personal concerns.

The application is designed to focus on mental health and emotional support rather than general-purpose question answering.

## Features

- AI-powered conversational support
- Context-aware responses
- User registration and login
- Password hashing for authentication
- Multiple chat conversations
- Chat history storage
- Automatic chat title generation
- Mental-health-focused conversation filtering
- PostgreSQL database integration using Supabase
- Environment-based configuration for sensitive credentials
- Streamlit-based web interface

## Technologies Used

- Python
- Streamlit
- OpenAI API
- Supabase PostgreSQL
- Psycopg2
- Python-dotenv
- Git
- GitHub
